# AJMS MARINE — React + Tailwind

Professional marine diving and ship services website starter.

## Pages
- Home
- About Us
- Services
- Individual Service Details
- Contact

## Updated UX
- Contact page uses WhatsApp, Call Us and Visit Us action cards instead of a form.
- Clicking a service from Home/Services opens a full-screen service image.
- Service title and summary are overlaid on the image.
- Detailed service information appears below the image.
- The same global Navbar and Footer remain on every page.

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Before production
Replace the placeholder WhatsApp number, phone number, email, location/Google Maps URL, logo and Unsplash images with AJMS MARINE's real company assets/details.
